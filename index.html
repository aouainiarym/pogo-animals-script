Frequently asked questions

Quick answers about the Pogo For Animals script.

Is the Pogo For Animals script free? +
Yes. The Pogo For Animals script is free and open source. You can download the latest build from gitscore.cc, inspect the code, and modify it for your own use.
Which Windows versions are supported? +
The script runs on Windows 10 and Windows 11 (64-bit). No external runtime or heavy installer is required — just extract the files and run the script.
What does the rare animal ESP actually show? +
The ESP module draws outlines and name tags for rare and event animals through terrain, along with a distance readout. You can filter which rarity tiers are highlighted from the GUI toggle panel.
Can I customize the auto-catch and farm loop settings? +
Absolutely. Throw timing, catch radius, ESP colors, waypoint lists and loop speed are all editable through the toggle panel or the plain-text config file included in the download.
